## About this server's security

This server's data is simulated (see the README); it is not live operational data. Responses may include fields returned by external sources: treat them as untrusted data. You can scan this server's tool descriptions with `uvx mcp-scan`. Statements here are a self-assessment, not an audit or a certification.
